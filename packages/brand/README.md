# noodl brand kit

A starter brand asset pack for noodl, a playful mind-mapping app.

## Contents
- `logo-horizontal-light.svg` / `.png` — transparent logo for light surfaces
- `logo-horizontal-dark.svg` / `.png` — transparent logo for dark surfaces
- `logo-horizontal-light-bg.svg` / `.png` — logo on an off-white background
- `logo-horizontal-dark-bg.svg` / `.png` — logo on a dark background
- `app-icon.svg` / `.png` — main butter-yellow app icon
- `app-icon-dark.svg` / `.png` — dark-mode app icon
- `app-icon-mono-black.svg` / `.png` — monochrome black variant
- `app-icon-mono-white.svg` / `.png` — monochrome white variant
- `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-48.png`
- `social-preview.svg` / `.png` — social/share preview artwork

## Brand colors
- Ink: `#151515`
- Warm white: `#FFFDF7`
- Butter: `#FFF4CC`
- Noodle gold: `#FFB83D`
- Dark surface: `#151515`
- Secondary text: `#6C675D`

## Suggested web usage
```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
<link rel="apple-touch-icon" href="/app-icon.png">
```

## Notes
SVGs are editable vector files. The horizontal wordmark uses a rounded system-font stack (`Nunito`, `Arial Rounded MT Bold`, `Arial`, sans-serif); for consistent typography across all systems, convert the wordmark text to outlines in your design tool or bundle Nunito with your product.
This is a starter identity kit, not a trademark or domain clearance.
